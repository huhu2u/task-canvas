### ③ Member（商户通）续约与账期资源风控
- **续约目标**：付费版续约率底线55%，各组按60%甚至80%追，与绩效强挂钩
- **续约技巧**：前置提醒、批量发送商户通提醒弹窗、销售自我筛选（与钱挂钩自然积极）
- **账期严控**：
  - 背景：账期门店感知风控过高，公司判断主要用于刷单而非真实交易
  - 政策：T+1+3个T+3后，风控高则不再增补；后续新商原则上不再提供账期
  - 要求：严格筛选质量，质量差的不给账期，珍惜现有资源

## 18:40 touwan-generating-ppt 调试记录（重要修复）

### 门店：康美经络养生馆（ID: 1484774627）

### 问题诊断 & 修复过程
1. **utils模块缺失**：skill安装在 `~/.claude/skills/`，但 run_full.py 硬编码 `~/.openclaw/skills/`，utils目录不存在
   - 修复：`cp -r ~/.claude/skills/touwan-generating-ppt/utils ~/.openclaw/skills/touwan-generating-ppt/`

2. **MCP server name不对**：fetch_data_mcp.py中`MCP_SERVER_NAME = "mcphub-server-sankuai-com-33d39fae2ba242"`，但实际注册的是`strategy_touhaowanjia_query`
   - 修复：改为 `MCP_SERVER_NAME = "strategy_touhaowanjia_query"`

3. **--http-url 导致token过期**：脚本传 `--http-url` 时，mcporter 把它当 ad-hoc server，用了旧名 `mcphub-server-sankuai-com-33d39fae2ba242` 对应的过期token，而不是 config 里 `strategy_touhaowanjia_query` 的新token
   - 修复：去掉 `--http-url` 参数，让 mcporter 直接从 config 读取 URL + token

### 最终效果
- 所有接口全部调通：singel_customer_ppt_data（今日/上月/快照/MTD）、rank、product_json、other_shop_traffic等
- PPT生成成功：康美经络养生馆_运营方案.pptx（22.4MB），已发送

### 永久规则（后续生成PPT时必须确认）
- `fetch_data_mcp.py` 的 `MCP_SERVER_NAME` 必须与 `mcporter config list` 里的名字一致
- `_run_mcporter_cmd` 不传 `--http-url`，否则token会用错
- 每次容器重启需重新执行 `mcp-setup.sh` 换票（token不持久化）
