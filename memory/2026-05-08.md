# 2026-05-08 会议纪要学习笔记

## 关键学习要点

### 1. 人员编制底线管理策略
- **核心原则**：人员满编是业务底线，不接受任何缺编理由
- **关键动作**：新人稳定后再允许旧人离职，避免断档风险
- **管理手段**：5月起实行"缺编即警告"的硬性考核机制

### 2. "3-6-9"进度跟进机制
- 下午3点、6点、9点定时反馈框架协议进度
- 针对缺口大的区域加大攻坚力度，先保量再控成本
- 实时掌握业务进展，避免月底被动

### 3. 企微建群效率优化方法
- **标准化流程**：加微信 → 企微建群 → 拉入王小慧 → 绑定门店
- **集中作业**：利用晚会时间通过IVR外呼集中加微建群
- **效率提升**：避免单纯依赖上门拜访，一分钟可解决3家门店

### 4. 店转（GTV）策略优化
- **小框架策略**：将大框架拆解为5000-20000元小框架，降低商户感知压力，提高履约率
- **案例驱动**：复用"萌宠乐园"案例，通过找准商户痛点（评分差、转化率低）切入
- **日目标管理**：销售带着明确的日店转目标出门，主管每日盘点框架缺口

### 5. 前置闭环管理思维
- **时间节点**：物料工单、职人码绑码等执行项要求在5月15日/20日前完成全月目标闭环
- **避免堆积**：前置完成执行项，避免月底集中作业

## 思考与应用
- 粤闽浙城市群可借鉴"3-6-9"跟进机制，针对框架协议、好店经营评分等核心指标建立定时反馈机制
- 企微建群效率提升方法可快速复制到区域内各城市组
- 小框架策略有助于降低商户签单压力，提升CPC/MEM签框履约率
