## 核心业绩看板字段映射（已定稿修复，2026-04-17上午）

### 两个文件的正确分工
- `PC业绩看板个人模版指标_YYYY-MM-DD.xlsx`（今日）→ **月度MTD数据文件**
  - 月累计GTV = `目标值 × 目标完成率`
  - 月累计CPC&QCPS = `目标值 × 目标完成率`
  - MEM收款额月累计 = `MEM收款额`列
  - GTV剔除率/有效新签/CPC新签/MEM续约率 = 对应非MTD列
  - ⚠️ 非MTD列的GTV/CPC是**月累计**，不是昨日单日

- `PC业绩看板全部指标_YYYY-MM-DD.xlsx`（昨日）→ **昨日单日数据文件**
  - 昨日GTV = AC列 `中小发_代运营高线城市_实付验证GTV（剔除风控+退款）`
  - 昨日CPC消耗 = U列 `CPC消耗额`
  - 昨日旺铺通 = AA列 `旺铺通消耗额`
  - 旺铺通月累计 = AA列（同上，此文件用于旺铺通月累计也对）
  - CPS交易收入月累计 = `中小发代运营高线城市_交易收入（剔除风控+退款）`
  - ⚠️ MEM收款额在此文件大部分为0（昨日单日），**不能**从此文件取MEM

## 物料铺设进度看板（2026-04-17建立）

**触发条件**：英杰发来「全国大区铺设数据」CSV + 「物料进度目标」xlsx

**数据来源**：
- 铺设数据：全国大区铺设数据_YYYY-MM-DDTXX_代运营业务组_合作商管理组_高线区域.csv
  - 筛选条件：城市组 = 高线粤闽浙城市群
  - 关键字段：门店ID / 物料名称（NULL=未铺设） / 审核状态（合格/不合格/未知） / 是否码动销
- 目标文件：物料进度目标-YYYYMMDD.xlsx（Sheet1，筛选「一级组织（城市群）」含「粤闽浙」）
  - 关键字段：代运营二级组织 / 作业池 / 单月覆盖目标 / 总覆盖目标

**代运营商关联方式**：铺设CSV通过门店ID关联好店底表获取代运营商（同zrq-analysis逻辑）

**达标口径**：审核状态 = 合格（不是已铺设数，而是合格数）
- 单月完成率 = 审核合格数 / 单月覆盖目标
- 总目标完成率 = 审核合格数 / 总覆盖目标

**输出3个Sheet**：
1. 「物料铺设进度看板」：6家+合计，含作业池/已铺设/待铺设/合格/不合格/未审核/单月目标/单月完成率/总目标完成率/总缺口/码动销
2. 「❌不合格门店」：不合格原因明细
3. 「📋未铺设门店」：物料名称=NULL的门店

**色阶**：完成率🟢≥100% / 🟡≥60% / 🔴<60%；缺口🟢=0 / 🟡≤10 / 🔴>10
