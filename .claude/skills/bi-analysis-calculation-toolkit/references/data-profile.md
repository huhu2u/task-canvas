# 数据集画像（data-profile）

## Skill概述

对数据集进行全面的质量体检和画像分析，在正式建模前快速建立对数据的整体认知。覆盖元数据概览、缺失值分析、唯一性与基数分析、极值范围、重复行检测、常量列检测、相关性冗余检测、数据类型推断质量、内存优化建议等维度，并为每个字段生成质量评分。

## 输入

- **数据文件**：CSV 或 Excel 格式的数据集路径
- 可选参数：
  - 重点关注的字段列表（逗号分隔）
  - 相关性冗余阈值（默认 0.95）
  - 输出目录

## 工作流程

### 第一步：加载数据与元数据概览

通过 Bash 工具执行以下命令（将 `{SKILL_BASE_DIR}` 替换为系统注入的 Base directory）：

```bash
python3 "{SKILL_BASE_DIR}/scripts/data_profiling.py" --input "<数据文件绝对路径>" [--columns "<字段1>,<字段2>"] [--corr-threshold 0.95] [--output-dir <输出目录>]
```

> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

脚本自动完成：
- 加载 CSV/Excel 文件
- 输出基础元数据：行数、列数、内存占用
- 统计各数据类型的列数分布（numeric / object / datetime / bool）

### 第二步：唯一性与基数分析

- 计算每列的唯一值数量和基数比例
- 自动推断字段类型：ID类（基数 > 95%）、分类变量（唯一值 <= 50）、连续/高基数
- 检测数据类型推断质量：识别存储为 object 类型但实际为数值的列

### 第三步：缺失值与零值分析

- 统计每列的缺失数量、缺失率
- 统计每列的零值数量、零值率
- 按缺失率排序输出

### 第四步：重复行与常量列检测

- 检测完全重复的行数
- 检测零方差列（所有值相同的常量列）
- 检测近常量列（唯一值 <= 2 的列）

### 第五步：极值与范围描述

- 对数值列计算 min / Q1 / median / Q3 / max / IQR / 极差
- 标记 IQR 异常值（< Q1 - 1.5*IQR 或 > Q3 + 1.5*IQR）的数量

### 第六步：相关性冗余检测

- 计算数值列间的 Pearson 相关系数矩阵
- 标记相关系数绝对值超过阈值（默认 0.95）的特征对
- 输出冗余特征对列表

### 第七步：内存优化建议

- 分析各列的 dtype 是否可以降级（如 float64 -> float32，int64 -> int16）
- 估算优化后的内存节省比例

### 第八步：字段质量评分

为每个字段生成质量等级：
- **健康**：缺失率 < 5%，无明显极值异常，非常量列
- **需关注**：缺失率 5%-30%，或有极值疑点，或类型推断有问题
- **问题严重**：缺失率 > 30%，或全为零/常量

## 核心输出物

1. **数据概览摘要**（CSV + 控制台）：行列数、类型分布、内存、重复行数
2. **字段质量清单**（CSV）：每个字段的缺失率、零值率、唯一值数、质量等级
3. **极值范围表**（CSV）：数值字段的 min/Q1/median/Q3/max/IQR/异常值数
4. **冗余特征对**（CSV）：高相关特征对列表
5. **内存优化建议**（CSV）：各列的当前类型、建议类型、预计节省
6. **常量列和类型问题列表**（CSV）：零方差列和类型推断异常列

## 质量检验标准

- 所有字段均被覆盖，无遗漏
- 缺失率数字与实际一致（可通过 df.isnull().sum() 验证）
- IQR = Q3 - Q1 计算正确
- 重复行数可通过 df.duplicated().sum() 验证
- 相关性矩阵对称且对角线为 1
- 质量等级判断标准一致、无遗漏
