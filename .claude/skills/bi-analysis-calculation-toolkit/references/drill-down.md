# 维度下钻与贡献分析

## Skill概述

通过层层拆解将总指标的波动定位到具体维度，量化各因子对总指标变化的贡献。支持的分析方法包括：

1. **维度下钻**：从汇总层到细分层，逐级定位波动来源，支持单维度和交叉维度（如维度A x 维度B）下钻
2. **贡献度分析**：量化每个维度值的绝对变化、增长率、贡献度百分比及百分点拉动
3. **杜邦分析**：乘法型复合指标的 LMDI 因子分解，附带敏感性分析（单因子假设变动对目标的影响）

## 输入

- **数据集**（必选）：CSV 或 Excel 文件
- **目标指标列名**（必选）：需要分析波动的数值列
- **维度列名列表**（必选）：按下钻层级顺序排列的分类列
- 基准期数据（可选）：通过时间列拆分或独立文件指定；若未指定则需提供基准期文件
- 因子定义（杜邦分析时必选）：乘法型因子对应的列名
- 敏感性变动幅度（可选）：杜邦分析敏感性测试的变动百分比，默认 +/-10%

## 工作流程

### 步骤一：数据探索

对数据集进行结构理解和关系探索：
1. 查看行列数、数据类型，识别数值型/分类型/时间型列
2. 探查维度的层级结构，形成自然下钻路径
3. 识别可能的交叉维度组合，为后续多层下钻提供依据

### 步骤二：维度下钻与贡献度分析

通过 Bash 工具执行以下命令（将 {SKILL_BASE_DIR} 替换为系统注入的 Base directory）：

**脚本功能**：
- 逐层按维度聚合，计算各维度值的基准值、当前值、绝对变化、增长率、贡献度
- 支持多级交叉维度下钻（如 `--cross-dims 维度A 维度B`），计算交叉组合的贡献
- 计算百分点贡献（各维度值的绝对变化占基准期总量的百分点拉动）

**调用方式**：

```bash
# 单维度逐层下钻
python3 "{SKILL_BASE_DIR}/scripts/dimension_drilldown.py" <数据文件> \
  --metric <指标列> --dims <维度1> <维度2> \
  --time-col <时间列> --current-period <当前期> --base-period <基准期> \
  --output-dir <输出目录>

# 交叉维度下钻
python3 "{SKILL_BASE_DIR}/scripts/dimension_drilldown.py" <数据文件> \
  --metric <指标列> --dims <维度1> <维度2> \
  --cross-dims <维度A> <维度B> \
  --time-col <时间列> --current-period <当前期> --base-period <基准期> \
  --output-dir <输出目录>
```

> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

**输出文件**：
- `drilldown_results.csv`：各单维度的详细分析结果
- `cross_drilldown_results.csv`：交叉维度分析结果（若指定了 `--cross-dims`）

### 步骤三：杜邦分析（乘法指标拆解）

通过 Bash 工具执行：

**脚本功能**：
- 使用 LMDI（对数平均迪氏指数法）对乘法型复合指标进行因子分解
- 精确量化每个因子对总指标变化的贡献度
- 敏感性分析：模拟单因子变动 X% 时目标指标的变化，生成 what-if 场景表

**调用方式**：

```bash
python3 "{SKILL_BASE_DIR}/scripts/dupont_analysis.py" <数据文件> \
  --factors "因子名1:列名1" "因子名2:列名2" \
  --time-col <时间列> --current-period <当前期> --base-period <基准期> \
  --target-name <目标指标名> \
  --sensitivity-pct 5 10 20 \
  --output-dir <输出目录>
```

> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

**输出文件**：
- `dupont_results.csv`：因子分解详细结果
- `dupont_sensitivity.csv`：敏感性分析结果

## 核心输出物

1. **多维下钻汇总表**：各维度的基准值/当前值/绝对变化/增长率/贡献度/百分点拉动（CSV + 控制台输出）
2. **交叉维度分析表**：多维度组合的贡献度分析（CSV）
3. **杜邦分解表**：各因子的 LMDI 贡献度（CSV）
4. **敏感性分析表**：各因子在不同变动幅度下对目标指标的影响（CSV）
5. **文字总结**：包含下钻路径、各层级主要拖累/支撑因素、重点关注维度建议

## 质量检验标准

- 所有维度的贡献度之和应等于 100%（符号保留，正负贡献均计入）
- 百分点拉动之和应等于总指标的百分点变化
- 杜邦分析中各因子的 LMDI 贡献度之和应等于 100%
- 敏感性分析结果应符合乘法关系的数学一致性
- 交叉维度分析的贡献度之和应等于对应单维度的总变化
- 文字总结中的数值与表格一致，分析深入专业
- 自检：按以上标准逐项验证输出结果
