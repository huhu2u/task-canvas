# 归因模型

## Skill概述

在多触点环境下公平分配转化功劳，覆盖从简单规则到算法模型的多种方法：

1. **规则归因**：首次触点、末次触点、线性归因、时间衰减归因
2. **Shapley Value归因**：基于博弈论的公平分配，渠道 > 8 时使用蒙特卡洛采样近似
3. **马尔可夫链归因**：基于移除效应评估各触点的不可替代性
4. **数据驱动归因**：基于逻辑回归的多触点归因（补充方法）

## 输入

- **必需**：用户行为路径数据，包含用户ID、触点（渠道）、时间、是否转化
- **可选**：转化金额列（用于金额归因而非次数归因）

## 工作流程

### 步骤一：提取用户转化路径

通过 Bash 工具执行以下命令（将 `{SKILL_BASE_DIR}` 替换为系统注入的 Base directory）：

```bash
python3 "{SKILL_BASE_DIR}/scripts/extract_paths.py" -i "<数据文件>" --user-col <用户ID列> --channel-col <触点列> --time-col <时间列> --convert-col <是否转化列> [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

- 按用户ID和时间排序，构建每个用户的触点序列
- 统计转化路径和非转化路径分布
- 输出路径汇总数据供后续分析使用

### 步骤二：规则归因

通过 Bash 工具执行：

```bash
python3 "{SKILL_BASE_DIR}/scripts/rule_attribution.py" -i "<数据文件>" --user-col <用户ID列> --channel-col <触点列> --time-col <时间列> --convert-col <是否转化列> [--logistic] [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。

- 计算四种规则归因：首次触点、末次触点、线性归因、时间衰减归因
- 时间衰减使用指数权重（越靠后权重越大）
- 所有方法结果归一化为百分比，验证总和 = 100%

### 步骤三：Shapley Value归因

通过 Bash 工具执行：

```bash
python3 "{SKILL_BASE_DIR}/scripts/shapley_attribution.py" -i "<数据文件>" --user-col <用户ID列> --channel-col <触点列> --time-col <时间列> --convert-col <是否转化列> [--n-samples 10000] [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。

- 渠道数 <= 8 时：精确计算所有联盟的边际贡献
- 渠道数 > 8 时：蒙特卡洛采样近似（默认10000次排列采样）
- 归一化输出各渠道的归因占比
- 输出收敛诊断（采样模式下）

### 步骤四：马尔可夫链归因

通过 Bash 工具执行：

```bash
python3 "{SKILL_BASE_DIR}/scripts/markov_attribution.py" -i "<数据文件>" --user-col <用户ID列> --channel-col <触点列> --time-col <时间列> --convert-col <是否转化列> [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。

- 构建渠道间的转移概率矩阵
- 逐一移除每个渠道，计算转化率下降幅度（移除效应）
- 基于移除效应归一化为归因占比

> **补充方法：数据驱动的逻辑回归归因**
>
> 在步骤二的 `rule_attribution.py` 脚本中通过 `--logistic` 参数启用，基于逻辑回归系数估计各渠道的独立贡献，作为规则归因和算法归因的补充验证方法。

## 核心输出物

1. **路径提取结果CSV**：用户路径汇总、高频路径统计
2. **规则归因对比表CSV**：四种规则方法的各渠道归因占比
3. **Shapley归因结果CSV**：各渠道Shapley值和归因百分比
4. **马尔可夫归因结果CSV**：各渠道移除效应和归因百分比
5. **控制台摘要**：多方法对比和关键差异说明

## 质量检验标准

- 所有归因方法的渠道占比之和 = 100%（误差 < 0.1%）
- Shapley Value在采样模式下验证收敛性（标准误 < 1%）
- 存在于转化路径中但归因为0的渠道需要标注警告
- 路径中出现的渠道数超过8时自动切换蒙特卡洛采样并提示
