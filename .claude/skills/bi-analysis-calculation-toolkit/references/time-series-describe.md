# 时间序列描述性分析（time-series-describe）

## Skill概述

描述数据随时间变化的历史轨迹，仅陈述"已经发生了什么"，不涉及未来预测。核心能力包括：

- 增长率计算：同比（YoY）、环比（MoM/WoW）、CAGR、几何平均增长率
- 滚动与累计计算：移动平均（MA）、指数加权移动平均（EWMA）、YTD累计、滚动求和
- 季节性模式识别：星期效应、月度效应、季节性指数
- 增长贡献分析：各子类别对总增长率的贡献拆解
- 聚合频率自动检测

## 输入

- 数据文件路径（CSV或Excel格式）
- 可选参数：时间列名、指标列名、时间粒度（D/W/M，默认自动识别）、子类别列（用于增长贡献分析）
- 若未指定时间列和指标列，自动识别并进行全指标分析

## 工作流程

### 步骤一：增长率计算

通过 Bash 工具执行以下命令（将 {SKILL_BASE_DIR} 替换为系统注入的 Base directory）：

1. 读取数据，解析时间列并按时间排序
2. 自动检测时间粒度（日/周/月/季/年）
3. 计算环比增长率（相邻周期变化率）
4. 计算同比增长率（去年同期变化率，需跨年数据）
5. 基期值为0时标记为"N/A"而非无穷大
6. 计算CAGR（复合年增长率）
7. 计算几何平均增长率（适用于波动较大的序列，比算术平均更准确）
8. 输出增长率表到CSV

运行方式：
```
python3 "{SKILL_BASE_DIR}/scripts/growth_rate.py" input.csv --time-col date --metric-col value \
    --freq auto -o growth_output.csv
```
> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

### 步骤二：滚动指标计算

通过 Bash 工具执行：

1. 读取数据，设置时间索引
2. 计算简单移动平均（SMA）：MA-7、MA-30（或自定义窗口）
3. 计算指数加权移动平均（EWMA）：对近期数据赋予更高权重
4. 计算YTD（年初至今累计值）
5. 计算滚动求和（如最近N天合计）
6. 输出含所有滚动指标的完整表到CSV

运行方式：
```
python3 "{SKILL_BASE_DIR}/scripts/rolling_metrics.py" input.csv --time-col date --metric-col value \
    --windows 7 30 --ewma-span 7 -o rolling_output.csv
```
> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

### 步骤三：季节性模式检测

通过 Bash 工具执行：

1. 按星期几聚合计算均值，检测星期效应
2. 按月份聚合计算均值，检测月度效应
3. 计算季节性指数（各周期均值 / 总均值），>1表示该周期高于平均
4. 如指定子类别列，进行增长贡献分析（各子类别对总增长的拉动）
5. 输出季节性指数表和增长贡献表到CSV

运行方式：
```
python3 "{SKILL_BASE_DIR}/scripts/seasonality_check.py" input.csv --time-col date --metric-col value \
    --category-col category -o seasonality_output.csv
```
> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

## 核心输出物

1. **增长率表**（CSV）：各期的环比增长率、同比增长率、CAGR、几何平均增长率
2. **滚动指标表**（CSV）：各期的移动平均、EWMA、YTD累计、滚动求和
3. **季节性指数表**（CSV）：星期效应指数、月度效应指数
4. **增长贡献表**（CSV）：各子类别对总增长率的贡献拆解（当有子类别时）

## 质量检验标准

- 移动平均窗口边界处使用 `min_periods=1`，避免NaN
- 基期为0时增长率标记为"N/A"，不产生无穷大值
- 环比/同比增长率是否存在异常极端值（>500%），需提示可能的数据问题
- 同比计算需确认数据跨年覆盖，不足时给出提示
- 季节性指数之和除以周期数应约等于1.0
- 增长贡献之和应等于总增长率（误差<0.1个百分点）
- 滚动窗口大小需根据数据频率合理选择，避免过度平滑
