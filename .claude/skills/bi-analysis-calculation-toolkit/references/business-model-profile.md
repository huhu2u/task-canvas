# 同期群-RFM-漏斗分析

## Skill概述

三个核心用户行为分析模型的一站式计算工具：

1. **同期群分析（Cohort）**：按注册时间分组，追踪各组用户在后续各期的留存率，支持灵活的分组粒度和留存曲线平滑
2. **RFM评分**：基于最近消费时间（R）、消费频率（F）、消费金额（M）三个维度进行量化评分，支持可配置分箱数
3. **漏斗转化分析**：计算多步骤路径的逐步转化率和总体转化率，支持时间窗口约束和步骤间中位转化时间

## 输入

- **同期群分析**：用户ID、注册日期、活跃日期
- **RFM分析**：用户ID、订单日期、订单金额
- **漏斗分析**：用户ID、事件名称、事件时间、步骤定义列表

## 工作流程

### 模型一：同期群留存分析

通过 Bash 工具执行以下命令（将 `{SKILL_BASE_DIR}` 替换为系统注入的 Base directory）：

```bash
python3 "{SKILL_BASE_DIR}/scripts/cohort_retention.py" -i "<数据文件>" --user-col <用户ID列> --signup-col <注册日期列> --active-col <活跃日期列> [--period M] [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。必须通过 Bash 工具执行上述命令。

- 支持灵活的分组粒度（月、周、自定义周期）
- 构建留存矩阵：行为分组时间，列为距分组的期数偏移
- 计算各期留存率（相对于第0期的比例）
- 可选留存曲线平滑（指数衰减拟合），输出拟合参数
- 输出完整留存矩阵CSV

### 模型二：RFM量化评分

通过 Bash 工具执行：

```bash
python3 "{SKILL_BASE_DIR}/scripts/rfm_scoring.py" -i "<数据文件>" --user-col <用户ID列> --date-col <订单日期列> --amount-col <金额列> [--bins 5] [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。

- 计算R（距最近消费天数）、F（消费频次）、M（累计金额）
- 使用分位数分箱打分（默认5分制，可配置3-10分）
- R反向打分（越小越好），F和M正向打分
- 处理低基数边界情况（唯一值少于分箱数时自动降级）
- 输出每个用户的RFM分数和综合得分

### 模型三：漏斗转化分析

通过 Bash 工具执行：

```bash
python3 "{SKILL_BASE_DIR}/scripts/funnel_analysis.py" -i "<数据文件>" --user-col <用户ID列> --event-col <事件列> --time-col <时间列> --steps "<步骤1>,<步骤2>,..." [--window 7] [-o <输出文件>]
```

> ⚠️ 禁止手写代码替代此脚本。

- 按定义的步骤顺序计算各步骤的用户数
- 支持时间窗口约束（用户需在N天内完成下一步才计入）
- 计算逐步转化率和总体转化率
- 计算各步骤间的中位转化时间
- 统计每步流失用户数

## 核心输出物

1. **留存矩阵CSV**：完整的同期群留存率矩阵
2. **RFM评分表CSV**：每个用户的R/F/M原始值、分数和综合得分
3. **漏斗转化表CSV**：各步骤用户数、逐步转化率、总体转化率、中位转化时间
4. **控制台摘要**：各模型的关键指标汇总

## 质量检验标准

- 留存率第0期应为100%（或接近100%）
- RFM各分位分箱后用户数分布相对均匀（极端偏斜时警告）
- 漏斗各步用户数单调递减（后步骤多于前步骤时警告数据异常）
- 时间窗口漏斗中，无法匹配时间的记录正确排除
- 所有边界情况（空数据、单用户、单步骤）能正确处理
