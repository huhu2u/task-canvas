# 异常检测

## Skill概述

识别不符合预期模式的数据点。根据数据维度和类型自动选择检测方法：

- **单变量检测**：单个数值字段的异常点识别，使用3-Sigma、IQR、MAD三方法投票，小样本场景补充Grubbs检验
- **多变量检测**：多字段联合判断，使用Isolation Forest与LOF集成，含自适应污染率估计
- **上下文检测**：结合时间背景判断异常，基于时序残差法，支持多种周期粒度

## 输入

- **必需**：数据集（CSV或Excel格式）
- **可选**：需要检查的字段名称（默认检查所有数值字段）
- **可选**：时间列名称（用于上下文异常检测）

## 工作流程

### 步骤一：数据探索

对数据集进行结构理解，识别数值型、分类型、时间型字段，检查空值率、基本统计特征，为方法选择提供依据。

### 步骤二：方法选择与执行

根据数据特征自动选择检测方法：

1. **单个数值字段** → 通过 Bash 工具执行（将 `{SKILL_BASE_DIR}` 替换为系统注入的 Base directory）：
   ```bash
   python3 "{SKILL_BASE_DIR}/scripts/univariate_anomaly.py" -i "<数据文件>" --column <字段名> [-o <输出文件>]
   ```
   - 3-Sigma（Z-Score）、IQR箱线图规则、MAD三方法投票
   - 样本量 < 30 时自动启用Grubbs检验替代3-Sigma
   - 输出归一化的综合异常分数（0-1），支持多方法集成评分

2. **多个数值字段** → 通过 Bash 工具执行：
   ```bash
   python3 "{SKILL_BASE_DIR}/scripts/multivariate_anomaly.py" -i "<数据文件>" --columns <字段1> <字段2> ... [-o <输出文件>]
   ```
   - Isolation Forest + LOF双算法集成
   - 自适应污染率估计（基于IQR的初始估计）
   - 自动处理边界情况：常数序列、全NaN列、样本不足

3. **有时间列且单字段** → 通过 Bash 工具执行：
   ```bash
   python3 "{SKILL_BASE_DIR}/scripts/contextual_anomaly.py" -i "<数据文件>" --time-col <时间列> --value-col <字段名> [-o <输出文件>]
   ```
   - 基于时间上下文的残差法（支持小时、星期、月份等多粒度）
   - 自动检测时间粒度并构建周期性基准
   - 对基准组样本不足的情况进行回退处理

> ⚠️ 禁止手写代码替代以上脚本。必须通过 Bash 工具执行对应命令。

### 步骤三：结果整合

汇总各方法检测结果，输出带有异常标记和异常分数的完整数据表。

## 核心输出物

1. **异常点标注CSV**：包含原始数据、检测方法、异常分数、是否异常的标记
2. **检测统计摘要**：异常点数量、占比、各方法检测结果对比（输出至控制台）
3. **异常特征描述**：每个异常点偏离均值的倍数、所处分位数等统计特征

## 质量检验标准

- 异常点占比合理（默认不超过总样本的5%，可通过参数调整）
- 单变量检测中至少2/3的方法认定才标记为异常
- 多变量检测中两种算法交叉验证，提高置信度
- 常数序列、全NaN列等边界情况能正确处理而非报错
- 样本量不足时自动降级到适合的方法并在输出中说明
